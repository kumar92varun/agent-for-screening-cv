## Critical Requirements (Must Have)
1. **Python proficiency** through real AI/ML projects—not just listing the language
   - Look for: specific frameworks used (TensorFlow/PyTorch), quantified accuracy metrics, real datasets
   - Red flag: Listed but no project proof
   
2. **Deep learning frameworks** (TensorFlow or PyTorch)
   - Passing evidence: explicit model architecture description (e.g., "multi-input NLP model with embeddings")
   - Failing evidence: listed but no project context
   
3. **ML fundamentals applied to projects**
   - Supervised learning with classification/regression (at least one)
   - Model evaluation metrics (accuracy, AUC, F1, etc.)
   - Feature engineering and/or hyperparameter tuning documented
   
4. **GenAI/LLM exposure** (critical for this specific role)
   - RAG systems, prompt engineering, LangChain, or LLM API integration
   - Recent projects (within 6 months ideal)
   
5. **End-to-end project ownership**
   - Clear problem statement, solution, and impact quantification
   - Not just assigned tasks—demonstrates decision-making

## High-Value Signals (Differentiators)
- **Peer-reviewed research or conference presentation** (very rare for freshers, indicates maturity)
- **Kaggle competition performance** (top 10-20% is strong; top 5% exceptional)
- **Multiple projects across different domains** (NLP, CV, tabular, signal processing shows breadth)
- **Formal certifications aligned with role** (IBM GenAI, Stanford ML Specialization—not just Coursera audit)
- **Quantified achievements throughout** (specific numbers, not vague claims like "improved performance")
- **Clear, error-free CV communication** (structured projects with action verbs, no passive voice)

## Acceptable Gaps (Non-Critical for Freshers)
- **No production deployment** (Docker, Kubernetes, cloud) — trainable on job; not core to AI fundamentals
- **No backend engineering** (REST APIs, databases, backend frameworks) — depends on role scope
- **No software engineering practices** (testing, CI/CD, Git workflow) — learnable; gaps in fundamentals are worse
- **No DevOps/cloud infrastructure** (AWS/GCP/Azure) — can be trained, but cloud-native deployment becoming expected
- **Limited internship experience** — research or projects can substitute; depth > breadth for freshers

## Red Flags (Disqualifying or Concerning)
1. **No core frameworks at all** (TensorFlow/PyTorch/Scikit-Learn missing entirely)
2. **No supervised learning projects** (only NLP or only computer vision without classical ML)
3. **Claims skills without project proof** (e.g., "Expert in Pandas" but no data manipulation in projects)
4. **Recent ML pivot** (certification just 2-3 months before interview with zero projects) — suggests lack of depth
5. **All work is personal/hobby projects with no real data/constraints** — concerning for production readiness
6. **Job-hopping or frequent short stints** without explanation (less relevant for freshers but watch patterns)
7. **Poor CV communication** (vague bullet points, passive voice, no metrics, grammatical errors)

## Assessment Framework

### Tier 1 (PASS - Strong)
- Python + TensorFlow/PyTorch demonstrated in 2+ ML projects
- GenAI exposure (RAG, LLMs, LangChain) with recent work
- ML fundamentals clear (supervised learning, model evaluation, feature engineering)
- Quantified results on multiple metrics
- Clear project ownership and communication
- Gap: no production deployment acceptable; learnable on job

**Example: Veer Gajarlawar**
- 4+ ML projects with Python, TensorFlow, scikit-learn
- Peer-reviewed research + conference publication
- Top 13% Kaggle ranking, 86.7% NLP accuracy, 44.4% dimensionality reduction
- Recent RAG project (Feb-Mar 2026) with LangChain
- All gaps (Docker, APIs, cloud) are trainable; core ML is solid

### Tier 2 (PASS - Acceptable)
- Strong in 1-2 domains (GenAI is huge plus)
- Production deployment shown (Flask/FastAPI + Docker) even if ML fundamentals less deep
- OR solid ML fundamentals + willingness to learn production side
- Credible quantified results

### Tier 3 (HOLD - Borderline)
- Has most fundamentals but unverified depth (no GitHub, claimed but unproven)
- OR missing one critical area but strong in others
- Requires phone screen to confirm

### Tier 4 (REJECT - Failing)
- Missing core frameworks entirely (no TensorFlow/PyTorch/Scikit-Learn)
- No supervised learning projects
- No quantified results (all vague claims)
- Inconsistent career or recent unprepared pivot to AI/ML
- Poor communication or professionalism

## Interview Probes by Verdict

**If PASS:** Brief confirmation call
- (1) Code walkthrough of strongest project (GitHub/Kaggle)
- (2) One whiteboard question on Python/data structures
- (3) Discuss learning plan for gaps (e.g., cloud/Docker)

**If HOLD:** Deeper technical phone screen
- (1) Detailed architecture design of RAG or NLP project
- (2) Whiteboard ML fundamentals (loss functions, cross-validation)
- (3) Code quality review if portfolio provided
- (4) Assess coachability and growth mindset

**If REJECT:** Letter explaining gaps
- Typically: missing frameworks, no ML projects, or too junior without evidence of capability

---

**Why:** This role requires someone who can hit the ground running with Python/PyTorch/NumPy/Pandas and modern AI patterns (RAG, LLMs). Production engineering (Docker/cloud) can be learned; core ML fundamentals cannot be acquired in first 30 days.

**How to apply:** Use this rubric to calibrate verdicts across multiple candidates. Peer-reviewed work and Kaggle rankings are rare—reward them. Gaps in production engineering are forgivable if ML depth is proven and attitude is learning-ready.
